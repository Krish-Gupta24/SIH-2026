# Simulation Templates

This directory holds baseline templates used by model generators:

- `base_minimal.idf`: Minimal valid EnergyPlus template containing standard Version, SimulationControl, HeatBalanceAlgorithm, and ShadowCalculation objects.
- `schedules/`: Standard occupancy, lighting, equipment, and heating setpoint schedules (e.g., residential continuous, intermittent, defense outpost occupancy).
- `design_days/`: Standard winter and summer design day definitions for extreme climatic zones (Leh/Ladakh, Kargil, Dras, Western Plains, Coastal).
- `conventions.osm`: OpenStudio standards template.
