# Simulation Engineering Test Cases

This directory contains verified engineering test models and ground-truth validation cases:

- `ashrae_140_case600/`: Standardized basic test case for validating zone conduction, solar gain, and envelope response.
- `ladakh_high_altitude_outpost/`: Reference sub-zero high-altitude shelter model under Leh extreme winter conditions (-30°C dry-bulb, high DNI solar radiation, low atmospheric pressure).
- `passive_solar_trombe_wall/`: Validation case for massive thermal storage wall with exterior glazing.
- `uninsulated_vs_insulated_comparison/`: Benchmark test case comparing bare stone masonry vs. multi-layer EPS/XPS insulated envelope.
